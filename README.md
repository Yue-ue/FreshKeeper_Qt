# 鲜存管家

鲜存管家是一款基于 Qt Widgets 和 SQLite 的本地离线食材管理与反浪费助手。它帮助用户记录冰箱中的食材，识别临期食品，并根据当前库存推荐可以制作的菜谱，从而减少遗忘和重复购买造成的浪费。

## 项目目标

项目围绕一次日常做饭过程设计完整的数据闭环：

```text
添加食材
  → 判断临期状态
  → 根据库存推荐菜谱
  → 烹饪或丢弃食材
  → 扣减库存并保存记录
  → 同步更新首页数据
```

项目以本地运行和离线使用为主，不依赖账号、服务器或网络接口。

## 主要功能

### 首页

- 显示当前库存食材数量；
- 显示临期食材数量；
- 展示需要优先处理的食材；
- 提供菜谱推荐和新增食材入口。

### 食材管理

- 新增、编辑、删除食材；
- 记录名称、分类、数量、单位和到期日期；
- 按名称搜索和按分类筛选；
- 自动计算正常、临期和过期状态。

状态判断规则：

```text
距离到期超过 3 天：正常
距离到期 0～3 天：临期
已超过到期日期：过期
```

### 菜谱推荐

系统预置常见菜谱，根据用户当前库存计算匹配情况，并优先推荐能够消耗临期食材的菜谱。

推荐评分规则为：

```text
推荐分数 = 已有食材数 × 10
         + 临期食材命中数 × 15
         - 缺少食材数 × 5
```

每条推荐结果展示菜谱名称、已有食材、缺少食材和推荐理由。该规则简单透明，便于理解和演示。

### 消耗记录

- 记录正常消耗和丢弃操作；
- 消耗后自动扣减库存；
- 保存食材名称、数量、单位、类型和时间；
- 显示本月正常消耗记录数和丢弃记录数。

## 技术方案

- 开发语言：C++
- 图形界面：Qt Widgets
- 数据库：SQLite
- 构建工具：qmake
- 开发环境：Qt 6.11.2 MinGW 64-bit
- 运行方式：Windows 本地桌面应用

## 数据库设计

项目使用 SQLite 保存本地数据，主要数据表如下：

```text
ingredients
  食材库存、分类、数量、单位和到期日期

recipes
  菜谱名称、简介和制作步骤

recipe_items
  菜谱与所需食材的对应关系

consumption_records
  正常消耗和丢弃历史
```

数据库会在程序首次启动时自动创建，数据库文件保存在系统应用数据目录中，不需要手动配置。

## 构建与运行

### 使用 Qt Creator

1. 使用 Qt Creator 打开 `FreshKeeper.pro`；
2. 选择 Qt 6.11.2 MinGW 64-bit 构建套件；
3. 点击构建并运行。

### 使用命令行

在 PowerShell 中执行：

```powershell
$env:Path = 'D:\software\qt\Tools\mingw1310_64\bin;D:\software\qt\6.11.2\mingw_64\bin;' + $env:Path
qmake FreshKeeper.pro
mingw32-make
```

生成的程序位于：

```text
build/release/FreshKeeper.exe
```

## 演示流程

建议使用以下流程展示项目核心价值：

1. 新增番茄和鸡蛋，并将番茄设置为临期；
2. 返回首页，查看临期提醒；
3. 打开菜谱推荐，查看番茄炒蛋的匹配结果；
4. 查看“可优先消耗临期番茄”的推荐理由；
5. 点击开始烹饪并确认消耗；
6. 查看库存减少和新增的消耗记录。

## 项目范围

本项目聚焦于本地食材管理和反浪费流程，暂不包含以下内容：

- 用户登录和多用户权限；
- 多设备联网同步；
- 在线菜谱爬取；
- 图片识别食材；
- 生成式人工智能推荐；
- 复杂财务统计。
